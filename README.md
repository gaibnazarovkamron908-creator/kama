# kama studio

Готовая статическая версия сайта для GitHub Pages.

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в его корень всё содержимое этой папки.
3. В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, папка `/ (root)`.

Главный файл сайта — `index.html`.
